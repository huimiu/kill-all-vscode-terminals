# Kill All Terminals

![kill-all-termials](/images/screenshot.png)

A simple VS Code extension that adds a "Kill All Terminals" button to the terminal panel.

## Features

- Adds a button to the terminal panel's title bar
- Clicking the button kills all open terminal instances at once

## Usage

1. Open the terminal panel
2. Click the kill icon button in the terminal title bar
3. All terminals will be closed
